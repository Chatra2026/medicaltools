# オピオイド換算

ベース（mg/日）とレスキュー（mg/回）を分け、経口モルヒネ相当量と各薬剤の等鎮痛量の目安を表示する、依存ライブラリのない静的アプリです。

## 使い方

`index.html` をブラウザで開くか、GitHub Pages の `/medicaltools/opioid/` を利用します。患者情報の入力欄はなく、入力値の保存・通信もありません。

- ベース：経口、坐剤、注射、フェンタニル貼付剤を比較します。
- レスキュー：速放性経口薬と注射の1回量を比較します。
- ベースの結果では、各薬剤の「変更時の開始・注意点」から、入力薬剤との組合せに応じた切替情報を確認できます。
- ベースに対するレスキュー参考範囲は、独立した折りたたみ欄に表示します。
- 持続注射：現在と変更先の薬剤総量（mg）・希釈後の総液量（mL）、現在の流速（mL/h）から理論等鎮痛流速を算出します。現在のレスキュー液量（任意）は独立して等量換算します。変更先のベース1時間量を用いたレスキュー参考値は別表示です。投与経路は現在・変更先で共通の選択です。皮下注で流速が1mL/hを超える場合は出典の注意を表示します。

## 根拠と制限

### 注射へのスイッチ候補

現在の薬剤1日量からフェンタニル注・ナルベイン注の等鎮痛量を計算し、ユーザーが選んだ採用規格を整数アンプルで使用する調製候補を表示します。入力した総液量・最低限確保するベース時間を満たす候補を、希望流速への比が近い順に最大3件表示します。この並び順は算術上の便宜であり、臨床上の推奨順位ではありません。

候補には薬剤総量・薬液量・生食の計算量・希釈後濃度・流速・ベースのみの計算上の持続時間・1時間量のレスキュー参考値を表示します。開始量は自動減量せず、空欄ならNCC等鎮痛量の計算例として明示。医師が決定した開始量を別入力すると再計算します。元の薬剤・1日量の変更で開始量入力を消去します。

製剤規格はPMDA電子添文で確認：フェンタニル「テルモ」0.1mg/2mL・0.25mg/5mL・0.5mg/10mL（2025年8月）；ナルベイン2mg/1mL・20mg/2mL（2026年7月）。院内採用・流通状況は自動判定しません。配合適否・安定性・保存期限・実用的な調製精度・ポンプ性能・残液・プライミング量・レスキュー分の予備は評価しません。

追加根拠：

- https://www.pmda.go.jp/PmdaSearch/iyakuDetail/430574_8119401A1020_2_02
- https://www.pmda.go.jp/PmdaSearch/iyakuDetail/470034_8219400A1071_1_05

ナルベインの換算比はNCC表（モルヒネ注の1/12.5）と添付文書（モルヒネ注の1/8目安）で異なります。NCC基準を維持し、候補画面で添付文書比による比較量を別表示します。フェンタニル貼付剤からナルベイン注への切替注意も、剥離直後の使用回避等の添付文書記載を優先表示し、17時間を固定の開始時刻とはしません。

出典：[国立がん研究センター中央病院 緩和医療科「オピオイド・鎮静換算表 v6（2025年4月）」](https://www.ncc.go.jp/jp/ncch/clinic/palliative_care/050/kansanhyo_ver6.pdf)。確認日：2026-10-13。換算比はPDF1ページ目、切替情報は4ページ目を使用。非公式の参考ツールです。

`conversion.js` に換算比・貼付規格・切替条件をまとめています。係数は「当該薬剤量 / 経口モルヒネ量」。坐剤の換算比の幅は区間として伝播します。

貼付剤は表の規格と整数の枚数から計算し、含有量をmg/日として扱いません。出力の貼付規格は表の基準値と一致するときのみ表示し、規格の補間・丸めはしません。他の値では、放出速度相当値と「規格への換算なし」を表示します。

アブストラル・イーフェンは等量換算の対象外。メサドン等、表に係数がない薬剤も対象外。投与量の自動決定、不完全交差耐性の減量、製剤規格への丸め、ポンプ設定、増量・追加投与指示は行いません。切替時刻は資料に明記された条件だけを表示し、資料に時刻がない組合せでは個別確認を表示します。処方には医師の評価が必要です。

持続注射の濃度 = 薬剤総量 / 希釈後総液量。ベース1日量 = 濃度 × 流速 × 24。変更先流速 = 変更先等鎮痛1日量 / 24 / 変更先濃度。レスキューは濃度 × 1回液量から独立して計算し、ベース1日量へ加算しません。フェンタニルを含め入力単位はmg（1000μg = 1mg）。ポンプ刻み、投与回数、ロックアウト、デッドスペース、残液、切替の交差耐性減量は計算しません。追加参照：出典PDF3ページ目の皮下注流速、5ページ目の濃度と投与速度。

## 検証

`node opioid/test.cjs`（リポジトリルートから）で、換算表の各列、坐剤区間、貼付規格、異常入力、切替条件、UIモード切替・結果の消去を検証できます。ブラウザでの視覚検証は未実施です。

`node opioid/infusion-test.cjs` で、持続注射の濃度・質量・流速・レスキュー独立換算、資料の濃度列、不正入力、UIの3タブ遷移、結果消去、皮下注流速警告を検証できます。

`node opioid/preparation-test.cjs` で、調製候補の質量保存・整数アンプル・液量上限・ベース持続時間・異常入力・ナルベイン切替注意を検証。`infusion-test.cjs` は追加の候補UI・開始量更新・4タブ遷移も検証します。

### 全量とポンプ刻み（2026-10-13追加）

変更先全量は50・100・250mLから選択、100mLを初期値とします。薬剤液量を含む全量であり、生食計算量 = 全量 − 薬剤液量。エイミーの参照取説ではMPバッグタイプは50・100・300mLで、250mLは調製全量の選択肢として表示します。250mL規格のMPユニットやCADDとの互換性を保証しません。

注射へのスイッチ候補では次の参照仕様を適用します（すべてmL設定モード）。

| 機種・参照資料 | 持続流量 | ドーズ |
| --- | --- | --- |
| エイミーPCA CAP-100 取説L23 p.43 | 0.1～30mL/h、0.1刻み | 0.1～50mL、0.1刻み |
| CADD-Legacy PCA 6300 取説p.55 | 0.1～50mL/h、0.1刻み | 0.05～9.9mL、0.05刻み |
| CADD-Solis VIP PCA 技術資料p.9 | 0.1～100mL/h、0.1刻み | 0.05～50mL、0.05刻み |

エイミーの実機下限欄は、参照取説の初期値0.5mL/hを表示。機種変更時にその機種の参照上下限を入れますが、機種・版・施設設定との実機照合が必要です。CADDのmg・μg設定モードには対応しません。

各組成候補で理論流速の下側・上側の設定可能値を表示し、実投与1日量、目標との差（%）、実流速でのベース持続時間を計算します。自動でどちらかを処方値として採用せず、開始量の自動減量も行いません。指定最低時間を満たす設定がない候補は除外し、皮下注時は上限1mL/hで探索。候補の並び順は、最小の絶対投与量誤差、次に希望流速への近さです。

ドーズは各設定流速の1時間量に対して、参照ドーズ刻み・範囲内の近傍値を参考表示します。施設ごとのドーズ上下限、ロックアウト、単位時間投与上限、薬剤ライブラリは未評価です。表示差は丸めによる算術上の差で、ポンプの実流量精度ではありません。

`node opioid/pump-test.cjs` で、設定刻みの境界、丸め後投与量、全量の質量保存、ポンプ範囲・皮下注流速上限、ドーズ刻みを検証します。

希望流速の入力欄は廃止し、1日量・規格・全量から調製候補と流速を自動計算します。候補の第二順位に使う内部基準は0.5mL/h（実機下限が高い場合は下限）であり、使用者への流速指示ではありません。
